# LizardInteractive Client 🚀

The official frontend repository for **lizardinteractive.online**. This project is a specialized Next.js build focused on extreme performance, accessibility, and clean architecture.

## 🛠 Tech Stack
- **Framework:** Next.js (Standalone Mode)
- **Styling:** Tailwind CSS
- **Performance:** 100/100 Google Lighthouse Goal
- **Deployment:** Google Cloud Run (Continuous Deployment)

## 🎯 Project Goals
- **Zero-Latency Navigation:** Leveraging Next.js App Router and server-side optimization.
- **Microservices Ready:** Built to communicate with `lizardinteractive.online_server` via secure REST API.
- **Honesty in Code:** 100% licensed software and libraries.
